# Genesis ARC V0.9 — 实验报告

## 研究问题
在随机二维迷宫中，数字生命能否在单步目标提示后依靠循环状态保持目标信息；当通行路径在运动中途关闭时，能否感知障碍并重新规划？模块化记忆/规划网络是否优于参数量接近的普通循环网络？

## 方法
- 地图：7×7；起点固定为中心；四个角落作为目标。
- 训练：每个随机种子3张地图，障碍密度13%；每张地图×4目标×静态/动态两种任务。
- 动态任务：第2步关闭一格通道；该格位于一条最短路径上，且关闭后仍存在从起点到目标的替代路径。
- 留出：每个种子4张全新地图，障碍密度20%；动态通道延迟至第4步关闭。
- 架构：普通循环网络308个参数；模块化双流网络302个参数，差异约1.95%。
- 演化：每种架构4个独立种子；每个种子16个个体、14代；保留总体、静态任务和动态任务历史冠军。
- 基线：随机策略、初始种群最佳个体（冻结 generation-0 champion）、BFS oracle。
- 反事实：先记录同一策略在开放通道下的有序轨迹，再选择一格位于该轨迹后段、且封闭后仍有替代路径的格子，在相同地图、目标和策略下执行通道关闭；只统计有效干预。

训练评估量：8次演化运行 × 14代 × 16个体 × 24个训练场景 = 43,008个个体-场景评估。

### 关键观察
1. 普通循环网络在动态留出任务的平均得分为0.0847，成功率16.70%；冻结 generation-0 champion 得分0.0556、成功率13.36%；随机策略得分-0.0419、成功率1.79%；BFS oracle成功率100%。
2. 普通网络在静态留出任务的平均得分0.0629、成功率14.06%，与冻结 generation-0 champion（0.0639、14.06%）基本没有差异。
3. 模块化网络的动态任务得分-0.0257、成功率3.45%；静态任务得分-0.0021、成功率6.25%。本轮没有证据支持模块化结构优于普通循环网络。
4. 训练群体平均适应度从第0代约-0.0304上升至第12代约0.1241，但留出成功率仍低。这说明训练改善没有充分转化为跨地图泛化。

有效干预中的轨迹在关闭通道后平均有约80%位置发生变化，但真正成功到达目标的只有1/72组（1.39%）。因此，智能体能够因障碍变化而改变轨迹，却几乎不能可靠地完成重新规划。**轨迹变化不等于成功规划。**

## 统计解释
配对 Bootstrap（以随机种子为重采样单位，4个种子）显示，普通网络动态任务得分相对 generation-0 champion 的平均差约+0.0290，探索性95%区间约[+0.0064,+0.0570]；普通网络相对随机策略约+0.1266。由于独立种子只有4个，这些区间不应被视为确认性证据。模块化与普通网络的架构比较也受小样本和计算量未严格匹配限制。

## 结论
- 本轮证明了训练适应度可以随代数上升，但泛化仍然很弱。
- 普通循环网络在动态留出任务中有一定改善；静态留出没有超过冻结初始冠军。
- 模块化结构没有显示优势。
- 反事实干预造成明显轨迹变化，但重新规划成功率极低。
- 尚不能声称出现了可靠的自主规划、通用智能或开放式演化。

## 下一步
V1.0 不应再扩张网络结构。建议先修复任务与学习信号：
1. 增加可解释的路径规划 curriculum：从单障碍绕行到多通道封闭。
2. 对训练和测试地图严格按地图家族隔离，避免布局泄漏。
3. 用等参数、等FLOPs、等评估预算比较架构。
4. 记录动作、碰撞、位置、隐藏状态和距离势能，定位失败是记忆丢失、局部感知不足还是探索不足。
5. 增加至少20–30个独立演化种子后再做确认性统计。
6. 将“动态通道关闭后成功到达目标”作为主要指标，而非轨迹差异或训练适应度。
