# Genesis ARC V2.3 — Latent Discovery & Online Evolution

**Status:** research prototype; staged on `research/v2.3-latent-discovery-online-evolution`, not merged.

V2.3 tests three bounded capabilities on finite 8-state maps:

1. **Latent-factor identifiability:** exact recovery with one independent anchor, and canonical relative-basis recovery plus explicit gauge ambiguity without an anchor.
2. **Active discrimination:** mutual-information query selection, compared with fixed-order and random queries, with held-out input validation and an unknown-map null hypothesis.
3. **Online dictionary evolution:** immutable dictionary snapshots, record version pinning, MDL candidate addition, budget pruning, and all-or-nothing in-memory migration.

## Modules

- `latent.py`: permutation algebra, factor recovery, gauge analysis, and consistency checks.
- `active.py` / `open_set.py`: information gain, posterior updates, and open-set validation.
- `online.py`: immutable versions, record pinning, migration, and pruning.
- `factorization_experiment.py`, `active_experiment.py`, `online_demo.py`: separate seeded protocols.
- `experiment.py`: reproducible runner; `analyze.py`: Wilson 95% intervals and summaries.
- `tests/`: 12 unit tests.
- `V2.3_REPORT.md`: methods, results, limitations, and V2.4 agenda.

The online memory experiment imports the exact codec from sibling `versions/v2.2/dictionary.py`; keep both version directories in the repository.

## Reproduce

Run from `versions/v2.3/`:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -c 'import experiment; experiment.selftest()'
python experiment.py --seeds 256 --noises 0 .05 .2 --out results_full
python analyze.py results_full
```

The checked-in results contain configuration and aggregate summaries. The full per-seed active and factorization rows are regenerated by the experiment command.

## Key results

- Anchored recovery, unanchored canonical consistency, and gauge invariance: 256/256 trials each.
- Without an anchor, at least `8! = 40,320` equivalent latent-operator tuples produce the same pairwise observations.
- At 20% noise, active correct-decision rate: 96.88% for in-set maps and 91.02% for out-of-set maps. Fixed query: 89.45% / 75.39%. Random query: 85.16% / 83.59%.
- At 20% noise, active false acceptance of unknown maps was 2.73%; fixed was 3.13%, random 2.34%. Active does not dominate every error metric.
- Online demo: abstract cost 168 to 136 bits; two old records remained decodable across the update and migrated with 100% round-trip success.

## Limits

- The pairwise relation structure is supplied by the synthetic experiment; V2.3 does not yet discover it from arbitrary unlabelled skills.
- The open-set null assumes uniform independent outputs; it is not a calibrated universal novelty detector.
- Online versioning is in-memory, not durable or crash-safe.
- Bit counts use V2.2's abstract cost model, not measured bytes, RAM, latency, or energy.
- This branch is not integrated with the V1.5.1 evolutionary ecosystem and makes no general-intelligence claim.
