# Genesis ARC V2.2 — 自组织知识字典

V2.2 研究一个有限状态环境中的问题：系统能否仅从已经观测到的技能映射中，发现可复用的操作表，并用这些操作精确编码后续复合技能？

本版本是**合成有限映射压缩实验**，不是完整数字生命生态系统，也不代表通用智能。它是 Genesis ARC 的独立研究分支，尚未与 V1.5.1 遗传种群/生态环境主线集成。

## 核心机制

- 候选字典只能从训练阶段已经观测到的技能映射中选择，不读取隐藏原语标签或留出集。
- 采用二元素前瞻，避免“单独加入任何一个原语都没有收益、两个原语组合后才产生收益”的贪心停滞。
- 在二元素种子后，按总描述长度的边际收益逐个增加字典项。
- 最多8个字典项，程序最大深度3。
- 不可精确表示的映射退回原始表存储；编码器不允许有损近似。
- 每个数据前缀重新拟合一次字典，用于比较锚点先到与随机到达的顺序影响。

## 复现

\`\`\`bash
pip install -r requirements.txt
python -c 'import experiment; experiment.selftest()'
python -m unittest discover -s tests -v
python experiment.py --seeds 16 --noises .05 .2 --out results
python analyze.py results
\`\`\`

## 目录

- \`dictionary.py\`：映射组合、程序枚举、字典选择、编码成本及无损解码。
- \`experiment.py\`：合成数据生成、噪声观测、主实验和隐藏原语留出实验。
- \`analyze.py\`：按随机种子汇总、配对 bootstrap 区间、顺序效应分析。
- \`v17_baseline.py\`：固定 DSL 对照所用的 V1.7 原语表；V2.2 核心算法不调用 V1.9 学习器。
- \`tests/\`：单元测试。
- \`results_full/\`：本次16种子/噪声组实验的原始 CSV、统计表和配置。

## 重要限制

1. 位数是明确列出的抽象存储成本模型，不是 Python 堆内存、真实二进制序列化或 SRAM 实测。
2. 观测映射由每个输入重复采样5次并多数投票估计；这不是主动学习策略。
3. 当前算法是前缀级批量重拟合，不是具有版本迁移、在线遗忘和随机访问能力的生产记忆系统。
4. 环境只有8个离散状态，隐藏操作是随机置换，程序深度最多3。
5. 对从未作为独立技能出现的隐藏原语，当前算法不能保证恢复其真实身份；不可编码的留出技能会回退为原始表。
