# Changelog

## V2.2
- Added self-organizing dictionary induction from observed finite-state skill maps.
- Added pair look-ahead to avoid zero-gain single-item greedy dead ends.
- Added raw, fixed-DSL, random-dictionary, no-pair and oracle comparisons.
- Added anchor-first/shuffled prefix experiments and held-out composition tests.
- Added a hidden-primitive condition where one latent primitive is never shown as an atomic skill.
- Added noisy map estimation, exact round-trip checks, paired bootstrap summaries and unit tests.
- Explicitly documents abstract bit accounting and the distinction between exact decoding and semantic map accuracy.
