# Genesis ARC V1.0 — 内部世界模型与自主规划实验报告

## 1. 研究问题

数字生命能否只依靠局部感知建立内部地图，在行动前模拟候选动作序列，并在通道中途关闭后重新规划？记忆与多步模拟分别贡献多少？遗传优化是否能进一步改善这些能力？

## 2. 方法与信息边界

- 环境：13×13网格，起点固定在中心。
- 感知：每步只观察当前位置周围3×3格的障碍状态。
- 目标：个体获得目标坐标，但不获得完整地图、最短路径或预设行动序列。
- 内部世界模型：在线占据地图（未知/空闲/障碍），通过局部感知逐步更新；地图记忆有可遗传的TTL。
- 内部模拟：beam search在内部地图上展开候选动作序列；未知格被视为可通行但带不确定性成本，已知障碍不可通行。
- 规划器不接收真实地图。真实地图只用于环境碰撞、场景生成和评测。
- 四邻接运动规则是手工给定的，**不是个体通过学习获得的动力学模型**。

基因组包含5个超参数：未知格惩罚、重复访问惩罚、模拟深度、beam宽度、地图记忆TTL。遗传算法优化这些参数，不演化beam-search算法本身。

## 3. 实验设计与样本量

- 独立演化种子：6。
- 每个种子：种群10个体、8代。
- 训练：每个种子2张随机地图、障碍密度18%、两个对角角落目标；每个地图—目标包含静态和动态版本，共8个训练场景。
- 留出：每个种子6张全新地图、障碍密度27%、训练中未出现的另一对角目标；每个地图—目标有静态版本，动态版本仅在能够找到有效替代路线时加入。
- 动态留出通道在第9步关闭。
- 对照：初始种群冠军冻结、固定参数内部规划器、无地图记忆规划器、单步模拟消融、局部反应式策略、随机策略、全地图BFS oracle。
- 反事实干预：先记录开放通道下成功轨迹；在第6步封闭该轨迹未来将经过的格子，并确认从干预时当前位置仍有替代路径；随后在同一地图、目标和策略下重跑。

### 主要观察

1. 演化内部模拟规划器在陌生静态地图上的成功率为 **87.50%**，动态地图为 **80.18%**。
2. 无地图记忆规划器分别只有 **45.83%** 和 **38.16%**，并出现大量重复访问。这支持持续空间记忆在本任务中的作用。
3. 单步模拟消融分别为 **76.39%** 和 **61.09%**。多步候选序列模拟在静态和动态任务中均有增益。
4. 局部反应式策略成功率为 **26.39%** 和 **23.74%**；随机策略没有完成目标。
5. BFS oracle成功率为100%，但它读取完整真实地图，只作为性能上界，不是信息条件公平的参赛者。

演化规划器在 **61次有效干预** 中，重新到达目标的成功率为 **88.5%**，轨迹平均差异率为 **60.0%**。无地图记忆规划器在有效干预中的重新规划成功率为 **58.1%**。冻结初始冠军和固定参数规划器与演化规划器相近或略高。

## 8. 结论

- **有证据支持**：在线内部地图记忆和多步候选动作模拟，在当前局部感知迷宫任务中优于无记忆、单步模拟和局部反应式消融。
- **初步支持**：当原路线被中途封闭时，拥有地图记忆的规划器通常能重新规划到达目标。
- **未证实**：遗传优化优于固定参数规划器或冻结初始冠军。
- **未实现**：个体学习自身动力学模型、规划算法本身的开放式演化、通用智能。
- **重要限制**：转移规则和beam search是手工设计；目标坐标直接提供；仅6个独立演化种子；随机障碍迷宫仍是简化环境。

## 9. V1.1 下一步

1. 将手工给定的运动模型替换为个体通过交互学习的动作后果模型，并独立测量预测误差。
2. 将beam search逐步替换为可遗传的规划模块，验证搜索机制能否由选择形成。
3. 加入移动障碍、资源消耗、有限能量和不完全目标信息。
4. 扩大至至少20–30个独立演化种子，并按地图家族隔离训练/测试。
5. 预先指定主要指标：陌生地图成功率、有效封路干预后的重新规划成功率、模型预测准确率和跨任务迁移。
6. 以等参数量、等计算预算比较普通网络、模块化网络和模型式规划。

**V1.0最可靠的发现不是“数字生命已经产生智能”，而是：在本实验中，持续的空间记忆和多步内部模拟显著改善了陌生地图导航及封路后的重新规划；遗传搜索本身的额外贡献尚未得到证明。**
